# PIÈCE-SÛRE AI — Backend

Version complète avec base SQLite locale.

## Démarrage

1. `npm install`
2. `npm start`
3. Ouvre `http://localhost:3000`

## iPad
Si le PC est sur le réseau :
`http://IP_DU_PC:3000`
Puis "Sur l'écran d'accueil".

## Données
Base SQL créée dans `data/app.db`. À sauvegarder régulièrement.
